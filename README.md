## Overview

Over the 2015–2025 seasons, NFL offenses threw less, ran more, and handed a growing share of the run game to their quarterbacks. This project documents that shift with reproducible numbers:

- **Report (`index.html`):** a scrolling editorial data story with a summary, 6 headline numbers, 11 findings (each with a headline, explanation, supporting numbers, a chart and a "show the numbers" table) and a full methodology section.
- **Dashboard (`dashboard.html`):** 7 filters, 6 live summary numbers, 5 linked charts, stat / measure / breakdown controls, a sortable and searchable data table with CSV export, and a reset button.

Every number is computed from the dataset in `data/`. No statistic is typed in by hand without being checked (see [Accuracy](#accuracy--reproducibility)).

The full column dictionary and cleaning log are in [`data/DATA_NOTES.md`](data/DATA_NOTES.md) and [`data/cleaning_log.txt`](data/cleaning_log.txt). The dataset audit (types, unique values, missing values, assignment compliance) is in [`analysis/audit_report.md`](analysis/audit_report.md).

**Cleaning summary:** 199,868 raw rows → removed 236 rows with no player ID (team placeholders) → removed 133,404 rows for non-offensive positions → **66,228 rows**. No values were modified and no outliers were removed. 6,530 rows where a player recorded no stat are kept but flagged (`no_stats_flag`) and excluded from per-player-game averages.

## Analysis

**Main questions:** How did NFL offensive production change from 2015 to 2025? Which parts of the offense grew and which shrank, and how does production differ by position, team and venue?

14 candidate findings were evaluated (see `analysis/audit_report.md`); 11 were selected:

| # | Finding | Key numbers |
|---|---|---|
| 1 | Passing volume fell to its lowest level of the period in 2025 | 259.1 → 224.9 pass yds per team-game (−13.2%) |
| 2 | The 300-yard passing game has nearly been cut in half | 132 → 68 games |
| 3 | Quarterbacks are getting sacked more often | sack rate 6.09% → 6.87% (peak 7.15%, 2023) |
| 4 | Offenses gave the ball away less than ever in 2025 | 1.43 → 1.14 giveaways per team-game |
| 5 | The run game gained ground, and got more efficient doing it | 108.7 → 117.0 rush yds per team-game; 4.13 → 4.36 yds/carry |
| 6 | Quarterbacks became a bigger part of the run game | QB share of rushing yards 11.8% → 15.2% (peak 16.9%) |
| 7 | Tight ends reclaimed targets as running backs lost them | TE share 24.0% in 2025 (period high); RB 21.7% → 18.0% |
| 8 | Home offenses out-gain visitors, except in 2020 | +11.9 yds/game at home; 2020 was the only reversal (−8.8) |
| 9 | Kansas City produced the most yards, by the slimmest of margins | KC 382.9 vs TB 382.7; NYJ last at 320.1 |
| 10 | Quarterbacks are the most dependable fantasy scorers | 14.04 PPR per game, 64% more than WRs |
| 11 | Derrick Henry is the era's yardage leader | 14,819 regular-season scrimmage yards |

**Key calculation rules** (full table in the site's methodology section):

- Seasons are compared **per team-game** (Σ stat ÷ distinct game-team pairs), because the schedule grew from 16 to 17 games in 2021.
- Rates are **ratios of sums** (e.g. completion % = Σ completions ÷ Σ attempts), never averages of per-game ratios.
- Team yards = Σ passing + Σ rushing yards. Summing `total_yards` across players would count every completion twice (the passer's and the receiver's yards).
- Touchdowns scored = rushing + receiving + return TDs (`total_tds − passing_tds`), for the same reason.
- Report findings use the regular season. The dashboard defaults to the regular season too, so the two pages match.

## Report page — `index.html`

Hero with the headline statistic → one-paragraph summary → 6 animated KPI cards → table of contents → 11 findings in three chapters (*The air game*, *The ground game*, *Where & who*) → methodology (source, what one row is, time period, cleaning, rows removed and why, a formula for every measure, limitations) → link to the dashboard.

Every number in the text is a `<span data-m="…">` bound to `data/report_metrics.json`. On load, `report.js` checks each one against the data. `analysis/verify.js` checks the same thing offline.

| Component | Details |

| **KPIs (6)** | Selected measure · Player-games · Players · Team-games · Scrimmage yards · Touchdowns scored |
| **Charts (6)** | Breakdown (columns, or ranked bars with logos/headshots for team/opponent/player; click a bar to filter) · **3D stadium** (32 team columns on a 3D field, linked to every filter) · Trend by position · Single-game distribution (histogram with median/average) · Team map (32 logo tiles by division, sequential colour, click to filter) · Top-10 players |
| **Table** | The numbers behind the breakdown for the current filters: sortable columns, search, pagination, totals row, CSV download |

## 3D & interactive features

| Where | Feature |
|---|---|
| Report hero | **3D football**, modelled in code (leather texture, seams, laces). Drag to spin, click to throw a spiral, tilts as you scroll |
| Report | **"Your call"**: draw your guess of how passing changed from 2016 to 2025, then reveal the real line and your average miss (mouse, touch or keyboard) |
| Report | **Metric toggles** on findings 1, 4 and 5 (e.g. rush yards/game ↔ yards/carry ↔ carries/game ↔ 1,000-yard rushers) |
| Report | **Head-to-head**: compare any two teams' yards/game, TDs/game and rank |
| Dashboard | **3D stadium**: every team as a column on a 3D field with its logo. Height = the selected measure (from zero by default; a clearly labelled "zoomed" mode stretches min→max). Hover for exact values, click to filter, drag to orbit, auto-rotate, zoom, reset view |
| Dashboard | **Click-to-filter**: click a season, position, conference, division, venue or season-type bar, a team or a player to filter; click again to undo |
| Dashboard | **Shareable links**: the URL records the current view (`#pos=QB&by=pos`…). **Copy link** puts it on the clipboard; Reset clears it |

The 3D views show the same numbers as the 2D charts and table (checked by `qa_browser.js`). They respect `prefers-reduced-motion`, render only when something changes, and load lazily.

## Running locally

The pages load JSON with `fetch()`, which browsers block for `file://` pages, so serve the folder over HTTP:

```bash
git clone https://github.com/Jalmanza12/run-it-back-nfl.git
cd run-it-back-nfl
python3 -m http.server 8000
# open http://localhost:8000
```

**Reproduce the data and numbers**

```bash
python3 analysis/clean_nfl.py        # optional: re-download raw nflverse files and rebuild the cleaned CSV
python3 analysis/fetch_headshots.py  # optional: rebuild player_headshots.csv
python3 analysis/analysis.py         # rebuild report_metrics.json, dashboard_data.json, audit_report.md
node analysis/verify.js              # accuracy check — expect "609 checks passed, 0 failed"
```

**Browser QA** (needs Google Chrome):

```bash
npm i --no-save puppeteer-core
python3 -m http.server 8000 &
node analysis/qa_browser.js http://localhost:8000   # expect "124 passed, 0 failed"
```

## Accuracy & reproducibility

1. `analysis.py` (pandas) computes every report statistic from the CSV.
2. `verify.js` recomputes each of them independently with the dashboard's JavaScript calculation layer (`js/metrics.js`) from `dashboard_data.json`. It also checks all 221 numbers written into `index.html`. **609 checks, 0 failures.**
3. `qa_browser.js` operates the real dashboard in Chrome: it switches stats, measures and breakdowns, applies each filter, clicks bars to filter, sorts and searches the table, opens a shared link, checks all 32 columns of the 3D stadium, plays the draw-it game, and resets. It compares the numbers on screen with the report. **124 checks, 0 failures.**

## GitHub Pages

The site is static and served from the `main` branch root (`Settings → Pages → Deploy from a branch → main / (root)`). All paths are relative, so it works under `/run-it-back-nfl/`. `.nojekyll` makes Pages serve the files unprocessed.

## Data & image sources

- **Statistics:** [nflverse-data](https://github.com/nflverse/nflverse-data) (`stats_player` and `players` releases). NFL data belongs to its respective owners.
- **Team logos:** loaded at display time from ESPN's public logo CDN (`a.espncdn.com`). Logos are trademarks of their teams and are shown for identification only. If a logo fails to load, a coloured badge with the team abbreviation is shown instead.
- **Player headshots:** URLs from the nflverse players table (hosted by NFL.com), requested as small face-cropped thumbnails. If a headshot is missing or fails, the player's initials are shown.
- **3D models:** the football, field, goalposts, stands and team columns are all modelled in code (`js/three-football.js`, `js/field3d.js`). There are no third-party model files, so there are no model licences to track.
- Images and 3D are decorative or supplementary. Every chart, number and table works without them, and the 3D views fall back to a message if WebGL is off.
